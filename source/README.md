# Hale source

`build.py` assembles these files into one self-contained page:

- `src/shell.html` page skeleton; `src/views/*.html` one file per section, in order
- `src/base.css` the shared design system (from Lymphatica); `src/hale.css` Hale's additions
- `src/js/*.js` scripts, joined in a fixed order inside one closure
- `src/refs.js` the evidence library, generated from `evidence/refs_hale.py` and PubMed records checked on 17 November 2026
- `src/heroart.svg` the start-page artwork, generated by `tools/heroart.py`
- `fonts/` the embedded open-licence fonts (SIL Open Font License 1.1)

To rebuild: `python3 build.py "Hale v2.html"`, then put the new file in `../versions/` and run `python3 ../tools/build_site.py`.
